## Agent skills

### Issue tracker

Issues are tracked using GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses standard roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository layout using root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
